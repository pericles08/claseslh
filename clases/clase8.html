Clase 8: la placa de red y la dirección MAC

En esta clase se estudia cómo un dispositivo se conecta a una red, cómo se identifica dentro de una red local y de qué manera circulan los mensajes entre equipos. El eje central será la relación entre la placa de red, la dirección MAC y los modos de transmisión unicast, multicast y broadcast.

Redes Capa de enlace Ethernet Wi-Fi Dirección MAC ARP

Objetivos de aprendizaje

  • Reconocer qué es una placa de red y cuál es su función dentro de una computadora o dispositivo móvil.
  • Diferenciar una placa Ethernet cableada de una interfaz inalámbrica Wi-Fi.
  • Comprender qué es una dirección MAC y cómo se organiza su estructura básica.
  • Explicar la diferencia entre dirección MAC, dirección IP y nombre de equipo.
  • Interpretar los modos de transmisión unicast, multicast y broadcast.
  • Relacionar el protocolo ARP con la comunicación dentro de una red local.
Pregunta inicial para pensar: si dos computadoras están conectadas a la misma red, ¿cómo sabe una de ellas a qué dispositivo físico debe enviarle la información?

1. La placa de red: NIC o Network Interface Card

La placa de red, también llamada NIC por sus siglas en inglés Network Interface Card, es el componente que permite que un dispositivo se comunique con otros dentro de una red. Funciona como una interfaz entre el sistema informático y el medio de transmisión: cable de cobre, fibra óptica u ondas de radio.

En una computadora de escritorio puede aparecer como una placa insertada en una ranura PCIe o como un circuito integrado en la placa madre. En una notebook o celular suele estar incorporada internamente. También existen adaptadores externos USB, muy usados cuando se necesita agregar Wi-Fi o reemplazar una interfaz dañada.

Funciones principales de una NIC

Enviar y recibir tramas

En la capa de enlace, la información viaja en unidades llamadas tramas. La NIC prepara, envía, recibe y filtra esas tramas.

Convertir señales

Transforma datos digitales en señales eléctricas, ópticas o de radiofrecuencia, según el tipo de red.

Identificar el dispositivo

Cada interfaz posee una dirección MAC que permite reconocerla dentro de la red local.

Tipos de placas o interfaces de red

Tipo de interfaz Medio de transmisión Forma de conexión Ejemplos de uso
Ethernet Cable UTP, STP o fibra óptica. Integrada, PCIe, adaptador USB o módulo SFP/SFP+. PC de escritorio, servidores, switches, routers, impresoras de red.
Wi-Fi Ondas de radio en bandas de 2,4 GHz, 5 GHz y, en equipos compatibles, 6 GHz. Integrada, Mini PCIe, M.2 o adaptador USB. Notebooks, celulares, tablets, impresoras inalámbricas, puntos de acceso.
Bluetooth Ondas de radio de corto alcance. Integrada o adaptador USB. Auriculares, teclados, mouse, periféricos y dispositivos IoT.

Velocidades de operación: valores orientativos

Las velocidades dependen del estándar, del cableado, del router o switch, de la distancia, de la interferencia y de la compatibilidad entre dispositivos. Por eso, las cifras máximas suelen ser teóricas.

Tecnología Estándar o denominación habitual Velocidad orientativa Comentario didáctico

Ethernet Gigabit Ethernet 1 Gbps Actualmente es una velocidad frecuente en placas y switches domésticos.
Ethernet Multi-Gigabit Ethernet 2,5 Gbps y 5 Gbps Permite mejorar redes existentes sin pasar directamente a 10 Gbps.
Ethernet 10 Gigabit Ethernet 10 Gbps Usado en servidores, redes troncales y equipos de mayor rendimiento.
Wi-Fi Wi-Fi 5 / 802.11ac Hasta varios Gbps teóricos Opera principalmente en 5 GHz.

Aclaración importante: en redes modernas con switches, la comunicación Ethernet suele funcionar en modo full-duplex, por lo que la antigua detección de colisiones perdió relevancia práctica. Sin embargo, sigue siendo útil estudiarla para comprender la evolución histórica de Ethernet y el acceso al medio.

2. La NIC en el modelo OSI

La placa de red participa principalmente en las dos primeras capas del modelo OSI. La capa física se ocupa de las señales y el medio de transmisión. La capa de enlace de datos organiza la información en tramas y utiliza direcciones MAC para identificar interfaces dentro de una misma red local.

Idea central: la dirección IP identifica un equipo dentro de una red lógica; la dirección MAC identifica una interfaz de red dentro de una red local.

3. Dirección MAC: Media Access Control

La dirección MAC es un identificador asociado a una interfaz de red. Tradicionalmente se la presentó como una dirección única grabada por el fabricante. En términos técnicos actuales, una dirección MAC universalmente única de 48 bits se conoce formalmente como EUI-48. Está compuesta por seis bytes que suelen representarse en hexadecimal.

Ejemplo de dirección MAC

00:1A:2B:3C:4D:5E

Cada par hexadecimal representa un byte. Se usan los símbolos del 0 al 9 y las letras A, B, C, D, E y F.

Formato general

48 bits = 6 bytes = 12 dígitos hexadecimales.

Puede escribirse con dos puntos, guiones o puntos, por ejemplo: 00:1A:2B:3C:4D:5E, 00-1A-2B-3C-4D-5E.

Estructura simplificada de una dirección MAC

Características importantes

  • La dirección MAC se usa para identificar interfaces dentro de una red local.
  • Los switches aprenden direcciones MAC para decidir por qué puerto deben reenviar una trama.
  • No cumple la misma función que una dirección IP: la MAC se vincula con la red local; la IP permite comunicación lógica entre redes.
  • En algunos sistemas modernos, especialmente celulares y notebooks, puede usarse aleatorización de MAC para proteger la privacidad al conectarse a redes Wi-Fi.
  • Una dirección MAC puede modificarse por software en ciertos sistemas. A esa práctica se la conoce como MAC spoofing.
Privacidad y seguridad: la dirección MAC puede servir para reconocer un dispositivo dentro de una red local. Por ese motivo, muchos sistemas actuales usan direcciones MAC aleatorias cuando exploran o se conectan a redes Wi-Fi públicas. Esto no reemplaza otras medidas de seguridad, pero reduce el seguimiento del dispositivo.

4. Tramas Ethernet: cómo viaja la información en la capa de enlace

En la capa de enlace, la unidad de información no se denomina paquete, sino trama. Una trama Ethernet incluye, entre otros datos, una dirección MAC de destino, una dirección MAC de origen, un campo que indica el tipo de contenido, los datos transportados y un control de errores.

5. Diferencia entre dirección MAC, dirección IP y nombre del equipo

Un error frecuente es pensar que la dirección MAC y la dirección IP son lo mismo. En realidad, cumplen funciones diferentes y pertenecen a niveles distintos de la comunicación.

Elemento Ejemplo Función principal Analogía
Dirección MAC 00:1A:2B:3C:4D:5E Identifica una interfaz dentro de una red local. Como el número de serie de una placa de red.
Dirección IP 192.168.1.25 Identifica un equipo dentro de una red lógica y permite comunicación entre redes. Como la dirección de una casa dentro de una ciudad.
Nombre del equipo PC-LAB-03 Permite reconocer un dispositivo con un nombre legible para las personas. Como el nombre visible de una persona o aula.
Ejemplo: una notebook puede tener una MAC para la placa Wi-Fi y otra MAC distinta para la placa Ethernet. Si además usa un adaptador USB de red, ese adaptador tendrá otra dirección MAC propia.

6. Modos de transmisión: unicast, multicast y broadcast

Cuando una placa de red envía una trama, debe indicar a quién está dirigida. Según el alcance del mensaje, la comunicación puede ser unicast, multicast o broadcast.

Unicast

El mensaje se dirige a un único dispositivo específico. Es el modo más común cuando una PC se comunica con un servidor, una impresora o una carpeta compartida.

Ejemplo: una PC envía un archivo a una impresora de red.

Multicast

El mensaje se envía a un grupo de dispositivos que forman parte de un mismo grupo de recepción. No todos los equipos de la red lo procesan.

Ejemplo: distribución de video en una red local o ciertos servicios de descubrimiento.

Broadcast

El mensaje se envía a todos los dispositivos del dominio de broadcast. Se utiliza cuando el emisor no conoce todavía la dirección específica del destinatario.

Ejemplo: una solicitud ARP en IPv4.

Dirección MAC de broadcast

La dirección MAC reservada para broadcast es: 

FF:FF:FF:FF:FF:FF

Cuando una trama tiene esa dirección como destino, todos los dispositivos de la red local deben recibirla y analizar si corresponde responder.

7. ARP: relación entre IP y MAC

En redes IPv4, el protocolo ARP permite descubrir qué dirección MAC corresponde a una dirección IP dentro de la red local. Es decir, ARP ayuda a responder la pregunta:

¿Quién tiene la IP 192.168.1.20? Indique su dirección MAC.
  1. La computadora A quiere comunicarse con la IP 192.168.1.20.
  2. Si no conoce la MAC de esa IP, envía una solicitud ARP en broadcast.
  3. Todos los equipos reciben la solicitud, pero solo responde el equipo que tiene esa IP.
  4. El equipo B responde con su dirección MAC.
  5. La computadora A guarda temporalmente esa relación IP-MAC en su caché ARP.
Actualización conceptual: ARP se usa en IPv4. En IPv6, una función equivalente se realiza mediante Neighbor Discovery Protocol o NDP, que trabaja de otra manera y utiliza mensajes ICMPv6.

8. Ejemplos prácticos para observar la MAC en una computadora

Los siguientes comandos permiten observar datos de red en una computadora. La consigna puede adaptarse según el sistema operativo disponible en el laboratorio.

En Windows

ipconfig /all

getmac

arp -a

ipconfig /all muestra información detallada de las interfaces. getmac muestra direcciones MAC. arp -a muestra la tabla ARP.

En GNU/Linux o macOS

ip addr

ifconfig

arp -a

ip neigh

Según la distribución o versión del sistema, algunos comandos pueden variar o requerir permisos.

Actividad breve de laboratorio

  1. Identificar la dirección MAC de la placa Wi-Fi o Ethernet del equipo.
  2. Registrar la dirección IP del equipo.
  3. Ejecutar arp -a y observar si aparecen otras direcciones MAC de la red local.
  4. Responder: ¿por qué aparecen direcciones IP y direcciones MAC en la misma tabla?
  5. Comparar los resultados con otro equipo del aula.

10. Caso integrador

En el laboratorio de informática hay una impresora de red con la IP 192.168.0.45. Una computadora necesita enviarle un documento para imprimir.

  1. La computadora reconoce la IP de destino: 192.168.0.45.
  2. Busca en su caché ARP si ya conoce la MAC de esa impresora.
  3. Si no la conoce, envía una solicitud ARP en broadcast.
  4. La impresora responde indicando su dirección MAC.
  5. La computadora envía la trama correspondiente a la MAC de la impresora.
  6. El switch utiliza su tabla de direcciones MAC para reenviar la trama por el puerto correcto.
Para debatir: ¿qué pasaría si dos equipos intentaran usar la misma dirección IP? ¿Sería un problema de dirección MAC o de configuración lógica de red?

11. Síntesis conceptual

Placa de red

Es el componente que permite conectar un dispositivo a una red. Puede ser Ethernet, Wi-Fi o de otro tipo.

Dirección MAC

Identifica una interfaz de red dentro de una red local. Se representa con 48 bits o 6 bytes en hexadecimal.

Transmisión

Puede ser unicast, multicast o broadcast, según si el mensaje se dirige a un equipo, a un grupo o a todos.

Conclusión: para que una red funcione, no alcanza con conectar cables o disponer de Wi-Fi. Cada dispositivo necesita una interfaz de red, una identificación física mediante MAC y mecanismos que permitan vincular esa identificación con las direcciones lógicas utilizadas por los protocolos de red.

13. Glosario mínimo

NIC
Placa o interfaz de red que permite conectar un dispositivo a una red.
MAC
Dirección de control de acceso al medio. Identifica una interfaz de red dentro de una red local.
OUI
Identificador organizacional único. Se asocia a los primeros 24 bits de muchas direcciones MAC.
Trama
Unidad de información de la capa de enlace de datos.
Switch
Dispositivo de red que reenvía tramas según direcciones MAC.
ARP
Protocolo usado en IPv4 para asociar una dirección IP con una dirección MAC en la red local.
Broadcast
Transmisión dirigida a todos los dispositivos de una red local.
Multicast
Transmisión dirigida a un grupo específico de receptores.
Unicast
Transmisión dirigida a un único destinatario.
