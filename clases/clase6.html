Presentación de la clase

Una herramienta conceptual para comprender cómo viaja la información en una red.

El modelo OSI permite organizar conceptualmente el proceso de comunicación en red mediante siete capas jerárquicas. Cada una cumple una función específica y, en conjunto, ayudan a interpretar cómo los datos viajan desde una aplicación de origen hasta un dispositivo de destino.

En esta clase, el modelo se relacionará con tecnologías LAN concretas como Ethernet, Wi-Fi (IEEE 802.11) y FDDI, además de dispositivos y conceptos que ya aparecen habitualmente en una red: direcciones MAC, direcciones IP, switches, routers y medios de transmisión.

Idea de partida. El modelo OSI no representa una red física concreta: funciona como una guía conceptual para separar funciones y comprender mejor qué tarea cumple cada tecnología dentro de una comunicación.

¿Qué es el modelo OSI?

Siete niveles para analizar una comunicación de red.

El modelo OSI (Open Systems Interconnection) fue creado como una forma de entender y diseñar sistemas de comunicación en red, dividiendo el proceso en 7 capas jerárquicas.

Cada capa posee una función específica. Al trabajar en conjunto, permiten interpretar cómo se preparan, transportan, direccionan, encapsulan y transmiten los datos desde un dispositivo hacia otro, incluso cuando participan tecnologías diferentes.

Una forma de pensarlo. Cada capa resuelve una parte del problema. Las capas superiores se relacionan más con las aplicaciones y los datos; las inferiores, con el direccionamiento, las tramas, el acceso al medio y la transmisión física.

Las siete capas del modelo OSI

De la interacción con las aplicaciones a la transmisión de bits.

Capa Nombre ¿Qué hace?
7 Aplicación Interactúa con las aplicaciones del usuario, como navegadores, chats o correo.
6 Presentación Prepara los datos: codifica, comprime o cifra la información.
5 Sesión Abre, mantiene y cierra sesiones de comunicación.
4 Transporte Divide los datos y participa en su entrega ordenada y completa.
3 Red Trabaja con direccionamiento IP y con la elección de rutas entre redes.
2 Enlace de datos Crea tramas, controla el acceso al medio y detecta errores.
1 Física Envía bits como señales eléctricas, ópticas o de radio.

Capas 7, 6 y 5

Se vinculan con las aplicaciones, el formato de los datos y el establecimiento de sesiones.

Capas 4 y 3

Se ocupan del transporte y del direccionamiento entre redes.

Capas 2 y 1

Trabajan muy cerca de la red LAN: tramas, MAC, medios físicos y señales.

Ejemplo cotidiano: enviar una foto

Una misma acción atraviesa varias funciones antes de llegar a destino.

Cuando enviás una foto mediante una aplicación de mensajería desde el Wi-Fi de tu casa, diferentes capas intervienen en distintos momentos del proceso.

  1. Capa 7 – Aplicación: la aplicación permite seleccionar y enviar la imagen.
  2. Capas 6 y 5: preparan los datos y administran aspectos vinculados con su representación y sesión.
  3. Capa 4 – Transporte: organiza la entrega de los datos.
  4. Capa 3 – Red: interviene el direccionamiento IP y la comunicación entre redes.
  5. Capa 2 – Enlace: los datos se organizan en tramas propias de la tecnología utilizada.
  6. Capa 1 – Física: la información se transmite mediante señales; en Wi-Fi, a través de radio.
Aplicación → Datos → Segmento → Paquete → Trama → Bits
Para interpretar el modelo. El objetivo no es memorizar una secuencia de palabras de manera aislada, sino reconocer qué función agrega cada capa antes de que la información se transmita.

¿Dónde se ubican las tecnologías LAN en el modelo OSI?

Ethernet, Wi-Fi y FDDI operan principalmente en las capas física y de enlace.

Las tecnologías LAN como Ethernet, IEEE 802.11 y FDDI operan principalmente en las capas 1 y 2 del modelo OSI.

Tecnología Capa 1: Física Capa 2: Enlace de datos
Ethernet (802.3) Cable UTP, conector RJ-45, fibra óptica. Tramas Ethernet y mecanismos de acceso al medio.
IEEE 802.11 (Wi-Fi) Señales de radio y frecuencias. Control de acceso inalámbrico y tramas Wi-Fi.
FDDI Fibra óptica y doble anillo. Control de acceso mediante ficha o token.
Conclusión importante. Estas tecnologías permiten la conexión entre dispositivos dentro de una red local. El direccionamiento entre redes diferentes corresponde a la capa 3, donde intervienen protocolos como IP.
6

Diferencias entre enlace de datos y red

Dos capas cercanas, pero con responsabilidades diferentes.

Capa 2 · Enlace de datos

  • Trabaja principalmente dentro de una red local.
  • Utiliza direcciones MAC para identificar interfaces.
  • Organiza la información en tramas.
  • Se relaciona con Ethernet, Wi-Fi y FDDI.
  • Un switch actúa principalmente en esta capa.

Capa 3 · Red

  • Permite la comunicación entre redes diferentes.
  • Utiliza direcciones lógicas, como las direcciones IP.
  • Trabaja con paquetes.
  • Se relaciona con protocolos como IP e ICMP.
  • Un router actúa principalmente en esta capa.
PC → Switch · Capa 2 → Router · Capa 3 → Otra red
Diferencia central. La capa 2 se ocupa de la comunicación dentro del enlace o red local inmediata; la capa 3 permite identificar destinos y encaminar información entre redes diferentes.

Síntesis conceptual

Integración de las ideas centrales de la clase.

El modelo OSI permite analizar una comunicación de red dividiendo sus funciones en siete capas. Esta organización ayuda a comprender por qué diferentes tecnologías intervienen en momentos distintos de una misma comunicación.

En una red LAN, tecnologías como Ethernet, Wi-Fi y FDDI se vinculan principalmente con las capas 1 y 2, mientras que el direccionamiento IP y la comunicación entre redes se relacionan con la capa 3.

Idea de cierre. Comprender qué hace cada capa permite interpretar mejor la función de un cable, una señal de radio, una dirección MAC, una dirección IP, un switch o un router dentro de una misma red.

Glosario

Conceptos clave para revisar la clase.

Modelo OSI
Modelo conceptual que organiza la comunicación de red en siete capas jerárquicas.
Capa física
Nivel que transmite bits mediante señales eléctricas, ópticas o de radio.
Capa de enlace
Nivel que organiza datos en tramas y trabaja con el acceso al medio y direcciones MAC.
Capa de red
Nivel encargado del direccionamiento lógico y del encaminamiento entre redes.
Trama
Unidad de información asociada a la capa de enlace de datos.
Paquete
Unidad de información asociada a la capa de red.
Segmento
Unidad de información asociada a la capa de transporte.
MAC
Dirección física utilizada para identificar interfaces dentro de la comunicación de enlace.
IP
Dirección lógica utilizada para identificar y comunicar dispositivos a través de redes.
Switch
Dispositivo que opera principalmente en la capa de enlace de datos y reenvía tramas dentro de una LAN.
Router
Dispositivo que opera principalmente en la capa de red y permite comunicar redes diferentes.
Ethernet
Tecnología LAN asociada principalmente con las capas física y de enlace de datos.
Wi-Fi
Tecnología inalámbrica de red local asociada a IEEE 802.11 y a las capas física y de enlace.
